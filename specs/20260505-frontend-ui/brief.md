# Product Brief: Frontend UI Iteration

## Goal
To build a beautiful, interactive, and decoupled frontend single-page application (SPA) using mainstream technologies (React + Vite) that allows users to interact seamlessly with the RAG microservice API.

## User Problem
The microservice backend exists but requires using cURL or API tools. Business users need an intuitive, highly aesthetic graphical interface. The engineering team requires a modern, scalable, and decoupled frontend architecture.

## Target Audience
Internal analysts, testers, and potentially end-users of the RAG system.

## Core Features
1. **Chat/Query Interface**: A premium input box to ask questions and view AI reasoning.
2. **Ingestion Interface**: File upload mechanism to ingest new PDF annual reports.
3. **High-End Aesthetics**: Dark mode, glassmorphism elements, smooth gradients, modern typography, and subtle micro-animations.

## Non-Goals
- User authentication/authorization.
- Persistent database-backed chat history across sessions.
